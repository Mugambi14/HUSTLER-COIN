# 🪙 HUSTL - Decentralized P2P Blockchain

HUSTL is a decentralized, peer-to-peer (P2P) blockchain built with Node.js. It features Proof-of-Work mining, digital signatures (secp256k1), and a distributed ledger.

## 🚀 How to Launch Your Node

### 1. Installation
Clone the repo and install dependencies:
\`\`\`bash
git clone https://github.com/Mugambi14/HUSTLER-COIN.git
cd hustl-blockchain
npm install
\`\`\`

### 2. Start the Network
Run the P2P node. This starts the WebSocket server for peers and the HTTP API for the wallet.
\`\`\`bash
node p2p-node.js
\`\`\`

### 3. Start Mining
Use the provided batch file or run the miner directly:
\`\`\`bash
node miner.js YOUR_WALLET_ADDRESS
\`\`\`

## 🛠 Features
- **P2P Discovery**: Connects to peers via WebSockets.
- **PoW Consensus**: SHA-256 mining with adjustable difficulty.
