Welcome to the HUSTL Protocol! 🚀
Thank you for your interest in contributing to Kenya's first decentralized P2P ledger with native mobile-money integration. We are building a global infrastructure for the "Hustle Economy," and we need your help to make it faster, more secure, and more accessible.

🛠 How You Can Help
We welcome contributions in several areas:

Core Protocol: Optimizing the SHA-256 hashing logic or the P2P "gossip" protocol.

Security: Auditing our secp256k1 implementation and transaction verification.

M-Pesa Integration: Helping us refine the Safaricom API V3 bridge for automated settlements.

UI/UX: Developing the HUSTL Graphical User Interface (GUI) and the Block Explorer.

Documentation: Improving this README or writing tutorials for new miners.

🚦 Getting Started
Fork the repository on GitHub.

Clone your fork to your local machine:

Bash
git clone https://github.com/Mugambi14/hustl-coin.git
Install dependencies:

Bash
npm install
Create a branch for your feature:

Bash
git checkout -b feature/AmazingFeature
📜 Contribution Rules
To keep the network stable, please follow these guidelines:

1. Security First
Never commit your ledger.json or any file containing private keys.

If you find a security vulnerability, please do not open a public issue. Instead, email [lewismhunga@gmail.com] so we can fix it privately.

2. Code Quality
Ensure your code passes all local tests.

Follow the existing Node.js style used in nodecoin.js.

Comment your code, especially when dealing with complex math or cryptographic functions.

3. Pull Request (PR) Process
Update the README.md with details of changes to the interface, if applicable.

Your PR should target the develop branch (not main).

The project lead will review your code. Once approved, it will be merged into the protocol.
